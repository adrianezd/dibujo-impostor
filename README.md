# Dibujo Impostor

Juego de fiesta de dibujo para grupos, hecho con HTML, CSS y JavaScript puros (sin frameworks, sin build, sin backend). Se juega pasando un solo móvil entre todos los jugadores.

**Juega aquí:** https://adrianezd.github.io/dibujo-impostor/

> Nota: si acabas de desplegar el sitio por primera vez, GitHub Pages puede tardar uno o dos minutos en publicarse.

## Cómo jugar

1. Elige jugadores (3-10), impostores (1-2) y categoría.
2. Cada jugador ve en privado su concepto: casi todos el mismo, el impostor uno parecido pero distinto — sin saber que es diferente.
3. Todos dibujan en papel su concepto, sin enseñarlo.
4. Se enseñan los dibujos a la vez y el grupo vota quién cree que dibujó algo raro.
5. Revelación: se descubre el impostor, su concepto, y si acertasteis la votación.

## Transparencia

Los pares de conceptos (animales, transporte, comida, lugares, objetos) son contenido original de este proyecto, sin relación con ninguna obra registrada.
